# Common Abbreviations
This file contains a table with a list of common abbreviations that can be used. Abbreviations should 
be avoided but the ones listed in this table are okay to use.

| Abbreviation | Meaning |
|-|-|
| adc | analog-to-digital converter |
| addr | address |
| af | alternate function |
| alt | alternate |
| comm | communication |
| config | configure |
| def | definition |
| di | disable |
| en | enable |
| err | error |
| ev | event |
| exti | external interrupt/event controller |
| fn | function |
| freq | frequency |
| ft | falling trigger |
| g_ | global |
| gpio | general-purpose input output |
| i2c | inter-integrated circuit interface |
| init | initialize |
| irq | interrupt request | 
| it | interrupt | 
| msec | milisecond |
| nsec | nanosecond |
| num | number |
| p_ | pointer (to) |
| param | parameter |
| peri | peripheral | 
| pre | prescaler |
| pwr | power controller |
| rcc | reset clock control |
| reg | register |
| rt | rising trigger |
| rtc | real time clock |
| rx | receive |
| sel | select |
| temp | temporary |
| tim | timer |
| tx | transmit |
| usart | universal synchronous asynchronous receiver transmitter |
| usec | microsecond |
